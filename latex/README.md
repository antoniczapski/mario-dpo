- `masters_thesis/` — the thesis. Build with:

  ```bash
  cd masters_thesis
  latexmk -pdf main.tex
  ```

- `main_report/` — earlier course report.
- `literature_review/` — literature notes and background reports.
- `verification/` — citation-verification scripts and report.
